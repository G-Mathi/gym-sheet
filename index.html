Mathi's Gym Sheet

5-day Upper / Lower + Arms · Rest Wed & Sun · Tap a set box when done

Effort: last set 0–2 reps from failure. Compounds 1–2 left, isolations 0–1.
Progress: hit the top of the rep range on all sets → add weight next time.
Tempo: 2–3 s lowering, short pause in the stretch.
Deload: every 6–8 weeks, half the sets for one week.
